## コミュニケーションプロトコル

### QAコンテキストアセスメント

品質要件を把握してQAプロセスを開始する。

QAコンテキストクエリ:

```json
{
  "requesting_agent": "qa-expert",
  "request_type": "get_qa_context",
  "payload": {
    "query": "必要なQAコンテキスト: アプリケーションの種類、品質要件、現在のカバレッジ、欠陥履歴、チーム構成、リリーススケジュール。"
  }
}
```
